## 二、电源
```text
开发板 3.3V 轨：输出 -> OLED、温湿度、光照、雨滴、LED ×4、蜂鸣器、INMP441
独立 5V 电源（5V / ≥2A）：输出 -> 门舵机；GND -> 开发板 GND（★ 必须拧一起，不共地舵机会乱抖）
```
除舵机外全部吃开发板 3V3，不用额外大电源；舵机必须独立 5V，不然一堵转就把电压拉跌、ESP32 反复重启。

## 三、不能接的脚
```text
GPIO26–32 -> 模组内部 SPI Flash，不能接
GPIO33–37 -> N16R8 的 Octal PSRAM 专用，接了就随机死机
GPIO19/20 -> USB D−/D+，接了 USB 认不出来
GPIO43/44 -> 串口日志 + 烧录口，不能接
GPIO45/46 -> 启动 strapping，上电必须为低或悬空
GPIO48    -> v1.1 板载状态灯，别外接
空闲可用   -> GPIO10–14 / GPIO21（原彩色 SPI 屏占的，换 OLED 后空出）、GPIO16 / GPIO41 / GPIO42 / GPIO47
```
坑 1（GPIO0）：KEY1 就接在 GPIO0，它同时是板载 BOOT 键 —— 按住 KEY1 再上电会进下载模式、程序不跑，这不是坏了；不想共用就把 KEY1 改到 40/41/42。
坑 2（GPIO38）：v1.0 板子的状态灯在 GPIO38，和麦克风 SCK 撞了 —— 这种板子把 SCK 挪到 16/41/42/47，或者关掉状态灯（`BSP_STATUS_LED_ENABLE=0`）；代码按 v1.1（GPIO48）配的，看板子丝印确认。

## 四、屏幕是单色 OLED（换屏记录）
原来那块 0.96 寸彩色 SPI 屏（ST7735S 160×80）实机确认硬件坏了：背光正常、供电正常，五根信号线逐根驱动毫无反应。换成 SSD1306 128×64 单色 OLED（I2C，0x3C/0x3D）后，原来占的 GPIO10–14 / GPIO21 全空出来了。
单色屏做不了需求②的"数字变红"，改成数字闪烁 + 蜂鸣器提示。I²C 只能跑 100kHz：400kHz 能应答地址、`panel_init` 也过，但推整页显存就 timeout，看着像"初始化成功却不显示"。

## 五、上电自检（开发者用）
烧录后开串口（115200 8N1），先看板子自己报的引脚和 [ OK ]（客户不装串口驱动也没关系 ——
App 连上蓝牙后会把这些状态显示出来）：
```text
BOARD:   I2C : SDA=GPIO8  SCL=GPIO9     屏 : SSD1306 128x64 (I2C, 0x3C/0x3D)
BOARD:   麦克风 : INMP441(I²S0) SCK=GPIO38 WS=GPIO39 SD=GPIO40 @16000Hz
BOARD:   [ OK ] status_led / i2c / adc
```
| 检查项 | 敲什么 | 期望 |
|---|---|---|
| 器件齐不齐 | `status` | 4 灯 + 门 + 蜂鸣器都在，I2C 有 `0x3C`（屏）和 `0x44`/`0x38`（温湿度） |
| 光照方向 | 遮住光敏后 `status` | `light_pct` 变小（变大就把 `BSP_LIGHT_ADC_INVERT` 取反） |
| 雨滴 | 往感应面滴水后 `sensor` | `rain_pct` 变大、天气变 `Raining!` |
| 灯 + 门 | `all on` / `all off`，`open door` | 4 灯全亮全灭；先关客厅灯再开门，门转且客厅灯自己亮 |
| 蜂鸣器 + 语音 | `cfg buzzer_on_c 26` 后捂热传感器，喊「你好小智」说"打开客厅灯" | 蜂鸣器响、`rms/peak` 变大，出现 `voice: cmd: led_living_on` |
| 屏 + 手机 | 看屏、打开 `web/index.html` | 屏有温湿度+天气+模式+四路灯；网页按钮全生效 |

## 六、需求原文（原 `智能家居设计.docx` 已删，正文抄在这里）
```text
智能家居设计
1.智能光控照明（联动LED）
 阈值控制：当光照强度低于设定阈值，自动点亮LED；高于阈值时灯光熄灭
tips：光控与语音控制有冲突，帮我加一个手动和自动模式。自动模式下，智能光控照明开启，手动模式下，语音控制开关灯

2.温湿度传感器
 温湿度OLED显示温度与湿度核心功能设计：
（1）正常显示：屏幕第一行显示 温度，第二行显示 湿度。
（2）异常提示：如果温度 ≥32℃，屏幕温度数字变成红色
· 自动刷新：每隔3秒刷新

3.雨滴传感器（联动温湿度OLED）
无雨状态：屏幕显示 天气: No Rain
有雨状态：屏幕显示 天气: Raining!

> 上面这段是最初的需求原文，保留不动。
> **实际成品有出入**：无雨改成显示「天气: Sunny」（英文，用户指定），雨滴传感器没接（读数不可信）时也显示「Sunny」而不是「--」。
> 有雨仍然是「Raining!」。`weather` JSON 的 `text` 字段同步改成 `Sunny`。
> 注：原来用的「晴天」两字**不在点阵字库里**（`font_cn_data.c`/`font_cn_extra.c` 都查不到"晴"），
> 屏上会画成空心方框；改英文后与 `Raining!` 一样是纯 ASCII，不再依赖中文点阵。

4.LED功能（联动语音控制）
语音控制开关客厅，厨房，浴室，卧室的灯
全灯亮，全灯灭

5.舵机（联动语音控制）
语音控制开关门，开门之后亮客厅灯

6.蜂鸣器
高温报警≥35℃，蜂鸣器就响 温度≤33℃时蜂鸣器关闭
或者语音控制关闭蜂鸣器

7.语音控制
（1）语音交互助手唤起
唤起语音助手，询问当前温湿度多少和天气怎么样，播报当前温湿度与天气。
（2）语音控制开关灯，开关门（或者关闭蜂鸣器）

8.终端交互
手机上可设置多个开关按键：
（1）客厅，厨房，浴室，卧室各灯的开关
（2）门的开关
（3）全灯亮灭开关
如果可以帮我弄一个温湿度和天气卡片显示在手机上吧
```
后面两处用户改过，代码按修订版走：
```text
（2）异常提示：如果温度 ≥32℃，屏幕温度数字闪烁，同时蜂鸣器给出提示音
高温提示≥32℃，蜂鸣器就响 温度≤31.5℃时蜂鸣器关闭
```
```text
tips：单色 OLED 没有颜色，所以"数字变红"改成"数字闪烁 + 蜂鸣器提示"；
      蜂鸣器与数字闪烁走同一个 32℃ 阈值，可用语音"打开蜂鸣器 / 关闭蜂鸣器"随时开关。
tips：蜂鸣器阈值随需求②一起降到 32℃（原 35/33），迟滞下沿取 31.5℃ 避免在阈值附近抖动响个不停。
```

## 七、排错（开发者用）
客户那侧先在 App 里看：连不上蓝牙 = 板子没上电/太远；连上但数据不动 = 传感器那一路没插好。
下面这些串口命令是给你自己定位用的：
```text
屏全黑        -> I2C 没通，敲 i2cscan 测不到 0x3C 就是 SDA/SCL 接反或没供电
屏半屏        -> I2C 速率太高或线太长，就是上面的 100kHz
屏整屏发灰    -> 模块批次差异，改 panel.c 的 INVON 开关
温湿度读不到  -> 看地址是 0x44(SHT30) 还是 0x38(AHT20)
光敏方向反了  -> BSP_LIGHT_ADC_INVERT 取反
雨滴一直下雨  -> 没接时 AO 悬空会飘；接上还这样就把 BSP_RAIN_ADC_INVERT 取反
蜂鸣器一直响  -> 敲 cfg buzzer_active_low 1 换极性
舵机抖动/重启 -> 舵机独立 5V 且和开发板共地
麦克风全 0    -> 敲 mic 看电平；L/R 必须接 GND，悬空是右声道
喊不醒        -> 先敲 mic 看电平，别急着调增益
字显示成方块  -> 字库缺字，改文案前先查 tools/dev/font_charset.txt
```
